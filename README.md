# UnitreeXR

UnitreeXR is a long-term robotics XR teleoperation workspace.

The project goal is to research and implement the pipeline:

```text
PICO 4 Ultra
→ XRoboToolkit
→ coordinate validation
→ Unitree teleoperation adapter
```

Current status:

```text
Phase 0 — Workspace Bootstrap
```

There is currently no real robot control code in this repository.
